# 决赛分数展示说明

本说明适用于决赛题目的选手界面、命令行反馈和上半场成绩汇总；不修改已批准的 GT、异常匹配规则或历史评分记录。

- 每道决赛题的展示满分为 **100 分**。评分器保留原始 0–10 分，展示分数为原始分乘以 10，最多显示两位小数。类型、实体、时间和证据四项在展示分数中的满分依次为 40、20、20、20 分。
- 上半场 `FT-01`、`FT-02`、`FT-03` 的总分满分为 **100 分**，计算方式为三道题展示分数的算术平均：`(FT-01 + FT-02 + FT-03) / 3`。三题是固定分母；未提交、尚未评分或没有有效分数的题目按 0 分计入。
- 原始评分中每条额外误报或重复事件扣 0.2 分，对应展示分数扣 2 分。漏报、空答案、证据有效性及时间容差仍按原决赛评分规则执行。
- PK 继续比较双方同题的异常分析分数；乘以 10 不改变高低顺序。原始分相同时仍按 51 服务器记录的有效提交时间决胜，不增加评委分。
- 练习与半决赛查询绘图题使用独立的 **10 分制**，不随此次决赛展示调整。

51 Public API 的决赛 `grade.score` 保留原始 0–10 分，并增加 `grade.display_score`、`grade.display_max_score=100`。上半场汇总接口的 `tasks[].score` 和 `total_score` 使用 100 分制，同时保留每题 `raw_score` 供审计。历史提交内容不重写；读取时按同一口径展示。
