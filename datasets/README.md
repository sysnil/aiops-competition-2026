
# 数据索引与恢复

`public-catalog/`仅包含51已导入Case的Manifest和可用元数据，不包含Metrics/Logs/Traces Parquet或原始Trace Index。

Manifest中的文件哈希、版本、时间窗和记录量用于从既有归档校验恢复。原路径指向原服务器布局，在新环境中需要保留版本关系或受控映射；不要编辑原Manifest来掩盖数据缺失或不同版本。

半决赛Q01–Q10关联SF-003、SF-005、SF-010，练习目录和决赛映射分别在questions下。SF前缀为历史数据Case编号，不表示该题一定属于半决赛。

未迁移评分数据库、选手答案、授权状态或原始故障运行目录。需要这些信息时应另行进行受控数据库/数据归档，而不是加入代码仓库。
