# 决赛异常分析评分规则 v2

状态：适用于所有队伍今后的正式决赛提交。本文件仅说明公开评分规则，不包含标准异常事件或私有证据。

每道决赛题满分 10 分。提交的异常事件与该题经批准的异常事件进行一对一匹配。每个匹配事件的得分由异常类型 40%、实体 20%、时间边界 20%、已核验的 Public 证据 20% 构成。起止时间各占时间分的一半；分别与对应标准边界相差不超过 300 秒时取得该部分分数。证据必须通过服务器的原始记录校验，并与所填实体和时间相关。

匹配事件的分数总和按标准事件数量平均。每个未匹配的预测和每个重复事件，再各扣最终 10 分制的 0.2 分。分数限制在 0 到 10 分。漏报事件不得分；空答案为 0 分；没有保底分。类型、实体、时间、证据四项均无正分的预测不能占用标准事件。无效或伪造的 Public 证据可能导致提交在评分前被拒绝。

规则版本：`final-balanced-evidence-v2.0`。规则在正式决赛开放前生效，对所有队伍一致。历史内部预览成绩不追溯修改，半决赛查询绘图题使用独立规则。权威评分和版本记录保存在 51 比赛服务器；选手 Web 显示服务器返回的分数。
